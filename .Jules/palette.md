## 2024-10-26 - aria-disabled safely requires JS and CSS updates
**Learning:** Replacing native `disabled` with `aria-disabled="true"` to keep buttons in the tab order (for screen readers to read their tooltips) also re-enables their native clickability and removes the browser's native `:disabled` CSS styling.
**Action:** When implementing `aria-disabled`, ALWAYS remember to explicitly add JS click guards (`if (el.getAttribute("aria-disabled") === "true") { e.preventDefault(); return; }`) and update the CSS selectors (`:disabled` -> `[aria-disabled="true"]`) to ensure the button remains functionally and visually disabled.
