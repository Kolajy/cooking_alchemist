# Simplified Slots Menu & Aesthetic Header Polish

This plan details the steps taken to simplify the Start Menu flow and convert the header buttons into a standardized, premium menu bar layout.

## Changes Made

### 1. Unified Start Menu Overlay
- Collapse the multi-screen Start Menu views into a single profile selector grid on launch.
- Render the 3 save slots directly below the title, with load (for saved slots) or start new (for empty slots) actions on click.
- Display a settings button at the bottom of the slots grid.

### 2. Standardized Top Menu Bar
- Wrapped stats counter, major navigation actions (Recipe Book, Progress Map), and utility buttons (Sound, Settings, Help) in a unified `.app-menu-bar` container.
- Configured a glassmorphic background layout with clean borders, aligned separators, and standardized spacing.
